## Contracts

### `src/git/gitClient.ts` — `createGitClient(config: Config): GitClient`
Runs `git` with `node:child_process` `spawn` (never a shell string). Every command gets env `GIT_TERMINAL_PROMPT=0`.
- **Auth:** when `config.githubToken` is set, pass
  `-c http.extraHeader=Authorization: Basic <base64("x-access-token:" + token)>`. Never put the token in the URL, in an
  error message, or in a log line.
- `cloneMirror(repoUrl, targetDir, signal)`: `git clone --mirror --filter=blob:none <repoUrl> <targetDir>`. Abort with `AbortSignal.any([signal,
  AbortSignal.timeout(config.cloneTimeoutMs)])`; on abort kill the child.
- `readRefTips(repoDir)`: `git for-each-ref --format=%(refname) %(objectname)` → `RefTips`.
- `hasAllCommits(repoDir, shas)`: `git cat-file --batch-check` with the SHAs on stdin; false if any line says `missing`.
- `listCommitsNewestFirst(repoDir, refTips)`: `git rev-list --timestamp --stdin` with the tip SHAs on stdin (one per
  line). Output lines are `<unixSeconds> <sha>`. Read them as a stream (readline), then sort with the pure function in
  `commitLister.ts`.
- `streamCommitDiffs(repoDir, shas, signal)`: an async generator. Runs
  `git -c core.bigFileThreshold=<config.bigFileThreshold> -c core.quotePath=false log -p --no-walk=unsorted --stdin
  --no-renames --no-color --no-ext-diff --format=<COMMIT_HEADER_FORMAT>` with the SHAs on stdin, reads stdout with
  readline, and yields each `CommitDiff` from the parser. Kill the child on abort. Merge commits produce no diff
  without `-m`/`--cc`, which is what we want.
- **Errors:** a non-zero exit throws `GitCommandError(message, isRetryable)`. Not retryable when stderr contains
  `Repository not found`, `Authentication failed`, `could not read Username`, or `not found` for the repo; retryable
  otherwise (network, timeout, abort by timeout). The message names the git subcommand and the repo/dir, and includes
  a trimmed stderr with the token removed.

### `src/git/commitLister.ts`
`sortCommitsNewestFirst(commits: CommitToScan[]): CommitToScan[]` — committer time descending, ties by `sha`
ascending. Plus `parseRevListLine(line: string): CommitToScan`.

### `src/git/diffParser.ts` — `createDiffParser(): DiffParser`
Pure, line-by-line state machine with no I/O, so it is unit tested without git:
- `pushLine(line: string): CommitDiff | undefined` — returns the previous commit when a new header starts.
- `finish(): CommitDiff | undefined` — returns the last commit.
- Header: export `COMMIT_HEADER_FORMAT` = a single line that starts with a marker unlikely in diffs, e.g.
  `%x01%H%x1f%cI%x1f%cn%x1f%ce%x1f%an%x1f%ae%x1f%s` (the message is the subject line). Parse it by splitting on `\x1f`.
- Track the current file from `+++ b/<path>` (`+++ /dev/null` = deleted file: no added lines). `Binary files … differ`
  = skip. Track the new-file line number from each `@@ -a,b +c,d @@` (start at `c`); `+` lines (not `+++`) are added
  lines at the current number and increment it; ` ` context lines increment it; `-` lines don't; `\ No newline at end
  of file` doesn't.
- `committedAt` is the `%cI` value converted to an ISO UTC string.

### `src/scanner/detector.ts`
`detectLeaks(line: string): DetectedLeak[]`, `DetectedLeak = { leakType: LeakType; leakValue: string }` (`LeakType`
from `src/domain/finding.ts`).
- Access key ID: `(?<![A-Z0-9])(?:AKIA|ASIA|ABIA|ACCA)[A-Z0-9]{16}(?![A-Z0-9])`, case-sensitive, all matches.
- Secret access key: only if the line matches an AWS secret keyword (case-insensitive), e.g.
  `aws.{0,20}secret|secret.{0,20}access.{0,5}key`; then every `(?<![A-Za-z0-9/+])[A-Za-z0-9/+]{40}(?![A-Za-z0-9/+])`.
  The boundaries matter: in `aws_secret_access_key=wJalr…EXAMPLEKEY` the value must be the 40 characters after `=`,
  not a run that starts inside `key=`.
- Patterns are module constants with names (`ACCESS_KEY_ID_PATTERN`, …).

## TL;DR (the worker fills this in when done)
**Asked to do:** Implement the `GitClient` contract with real `git` commands, a pure parser for `git log -p` output, a
commit sorter, and the AWS key detector, with tests.

**How I did it:**
- `src/git/gitClient.ts`: one helper, `streamGitLines`, spawns `git` (no shell, `GIT_TERMINAL_PROMPT=0`, token as an
  `http.extraHeader` on every command so lazy blob fetches work too), writes SHAs to stdin, yields stdout lines through
  readline, and throws `GitCommandError` on a non-zero exit. Every method is built on it.
- `src/git/diffParser.ts`: a state machine. It reads `+++ b/<path>` and `Binary files` only between `diff --git` and the
  first `@@`, so an added line `++x` (shown as `+++x`) is not taken for a file header.
- `src/git/commitLister.ts`: `parseRevListLine` (regex) and `sortCommitsNewestFirst` (time desc, sha asc, no mutation).
- `src/scanner/detector.ts`: the three named patterns from the brief; secret keys only on lines with a keyword.

**Decisions / tradeoffs:**
- `streamCommitDiffs([])` returns nothing: with empty stdin `git log` falls back to HEAD (checked by hand).
- `log` also gets `--src-prefix=a/ --dst-prefix=b/`, so a user's `diff.noprefix` config can't break the parser.
- `hasAllCommits` sets `GIT_NO_LAZY_FETCH=1`; otherwise a missing SHA in a blobless clone makes git ask the remote for it.
- Ignored `error` listeners on the child and on stdin: an abort or an early git exit would otherwise crash the process
  (EPIPE). The exit code reports the failure instead.
- Any abort (caller or timeout) is a retryable `GitCommandError` (empty stderr). The runner knows when it aborted.
- Not-found pattern is `repository '…' not found` (git's wording), not a bare `not found`.
- The stderr in errors keeps the last 2000 chars, with the token and its base64 header value replaced by `***`.
- A path that git quotes (control characters or `"`) is kept quoted; rare, not handled.
- `gitClient.ts` is ~190 lines (over the ~150 aim); the brief allows no new files to split the process helper into.

**How to verify:** `npm run check`; or `npx vitest run test/git test/scanner/detector.test.ts` (25 tests). The
`gitClient` tests build a 3-commit repo (two branches, fixed dates, one fake key) in a temp dir and also mirror-clone it
via `file://`.

**Follow-up fix (after the end-to-end run):**
- Detector: the secret keyword is now identifier-like only (`aws[_-. ]?secret`, `secret[_-. ]?access[_-. ]?key`,
  case-insensitive). The old `aws.{0,20}secret` matched the fixture's markdown row `aws.env | 3 | secret`. A 40-char
  candidate that is pure lowercase hex (a git SHA) is skipped (`GIT_SHA_PATTERN`). The fixture row is now a test.
- Config: an empty `GITHUB_TOKEN` is treated as no token (`test/config.test.ts`).
